# Explainable Lending XAI

A platform for explainable and fair lending decisions using Machine Learning.

## Tech Stack
- **Backend:** FastAPI, XGBoost, SHAP, Fairlearn, Evidently
- **Frontend:** React 18, Vite, TailwindCSS, Recharts

## Getting Started

Run the full stack via Docker Compose:

```bash
docker compose up --build
```

The backend will be available at `http://localhost:8000/health`.
The frontend will be available at `http://localhost:5173`.
